# Sprint 7

## Objetivos (Sprint Goal)
Todo lo que espera a la persona tiene un turno único, dado por qdd una sola vez, con el mismo orden y las dependencias marcadas en el panel y en el teléfono (RFC 0019).

## Certification-Driven Development (CDD v1.1)
Este sprint se rige por un contrato estricto de escenarios exhaustivos.
El agente debe implementar el código y los tests para el **Happy Path**, **Error Paths** y **Edge Cases** definidos en `sprint-7-cert.yaml`.

---
*Gobernanza QDD: Este archivo y su YAML asociado guían el desarrollo. Usa 'qdd certify' o ejecuta los tests directamente.*
