# Sprint 10

## Objetivos (Sprint Goal)
La documentación pública de QDD en GitHub y npm (README, guías, referencia, arquitectura, CONTRIBUTING, especificación, RFC y la ficha del repositorio) describe lo que QDD es y hace en la 2.10.0, sin afirmaciones que el código no sostenga, y una prueba avisa cuando vuelve a quedar atrás. Pedido de la persona (2026-11-24): «ya es hora de actualizar nuestro github para que refleje la verdad de nuestro framework a lo que es hoy qdd», «todo lo que es la documentación que está en github está desactualizada». Los escenarios los derivó la IA de ese pedido; la persona puede corregirlos.

## Certification-Driven Development (CDD v1.1)
Este sprint se rige por un contrato estricto de escenarios exhaustivos.
El agente debe implementar el código y los tests para el **Happy Path**, **Error Paths** y **Edge Cases** definidos en `sprint-10-cert.yaml`.

---
*Gobernanza QDD: Este archivo y su YAML asociado guían el desarrollo. Usa 'qdd certify' o ejecuta los tests directamente.*
